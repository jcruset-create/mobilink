# Icono de aplicación — Mobilink StockFlow

`app_icon_1024.png` es el icono maestro: 1024×1024, RGB **sin canal alfa** (App Store
rechaza los iconos con transparencia) y sin esquinas redondeadas (iOS aplica su propia máscara).

De aquí se derivan los tamaños del `AppIcon.appiconset` de iOS cuando se genere `ios/`,
y los `mipmap-*` de Android si en algún momento se decide sustituir el icono actual.
